# singbox-deploy 小白版使用说明

这是一个给 **Linux 服务器** 用的 Sing-box 一键安装/管理脚本。

如果你完全没接触过这些东西，也没关系。这个说明会尽量用最容易懂的话告诉你：

- 这脚本是干嘛的
- 你要准备什么
- 怎么安装
- 安装时每一步大概该怎么选
- 装完以后怎么看链接、怎么管理、怎么卸载
- 连不上时先查哪里

---

## 这脚本是干嘛的

它是一个帮你在服务器上快速装好 Sing-box 的脚本。

它可以帮你：

- 安装 Sing-box 服务端
- 生成客户端链接
- 用菜单管理协议
- 新增 / 删除 / 改端口
- 管理多个 VLESS Reality
- 一键卸载
- 基础支持 IPv6 链接生成

支持的协议包括：

- SS（Shadowsocks）
- HY2（Hysteria2）
- TUIC
- VLESS Reality
- AnyTLS

---

## 你要先准备什么

在运行脚本前，你至少要有：

### 1）一台 Linux 服务器

推荐：

- Debian
- Ubuntu
- Alpine

### 2）root 权限

先执行：

```bash
whoami
```

如果输出是：

```bash
root
```

就可以继续。

如果不是 root，可以先执行：

```bash
sudo -i
```

### 3）服务器网络正常

服务器需要：

- 能联网
- 能下载 GitHub raw 内容
- 能下载 sing-box

### 4）端口要能放行

这是很多新手最容易漏掉的地方。

脚本能帮你装服务，**但云平台安全组 / 系统防火墙不一定会自动帮你开好**。

所以你还要确认：

- 云服务器控制台里，端口已经放行
- 如果用了系统防火墙，也要自己放行

如果你用 IPv6，还要确认：

- IPv6 入站也放行了

---

## 怎么安装

直接执行：

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/admintors/singbox-deploy/main/run.sh)"
```

或者：

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/admintors/singbox-deploy/main/install-singbox-yyds.sh)"
```

---

## 安装时不会选怎么办

这里给你一个最省心的思路。

### 协议怎么选？

如果你完全不懂，建议先这样：

- 主力开：`VLESS Reality`
- 可选再开：`SS`
- `HY2 / TUIC / AnyTLS` 先不动

这样最简单。

---

### 部署模式怎么选？

一般会看到：

```text
1) 直连落地（默认）
2) 通过上游 Shadowsocks 中转指定 VLESS
```

如果你不懂，**直接选 1**。

也就是：

```text
直连落地
```

只有当你明确知道自己有“上游 SS 节点”要拿来中转时，才去选 2。

---

### “节点连接 IP 或 DDNS 域名”填什么？

意思是：客户端最终要连接哪个地址。

你有几种选择：

#### 方案 1：直接回车

留空就行，脚本会自动探测公网 IP。

适合大多数人。

#### 方案 2：填域名

比如：

```text
node.example.com
```

如果你有自己的域名，推荐填域名。

#### 方案 3：填 IPv4

比如：

```text
1.2.3.4
```

#### 方案 4：填 IPv6

比如：

```text
2408:xxxx:xxxx::1
```

现在脚本已经做了基础 IPv6 兼容，生成链接时会自动处理 IPv6 格式。

但你要确认：

- 服务器真的有 IPv6
- 云平台 / 防火墙也放行了 IPv6

---

### 端口怎么选？

如果你不会选：

- 尽量别和现有服务冲突
- 用脚本默认值最省事
- 改端口后，旧链接通常会失效

所以：

**如果已经能用，就不要频繁乱改端口。**

---

## 安装完成后怎么管理

安装完成后，输入：

```bash
sb
```

就能进入管理菜单。

一般会看到类似：

```text
1) 链接与配置
2) 协议管理
3) VLESS Reality 管理
4) 中转管理
5) 服务管理
0) 退出
```

---

## 每个菜单是干嘛的

### 1）链接与配置

你最常用的地方。

这里可以：

- 看客户端链接
- 重新生成链接
- 看配置文件位置
- 手动改配置

如果你只是想把节点导入客户端，通常来这里就够了。

---

### 2）协议管理

这里可以管理：

- SS
- HY2
- TUIC
- AnyTLS

支持：

- 新增
- 删除
- 改端口

---

### 3）VLESS Reality 管理

专门管理 VLESS Reality。

支持：

- 查看列表
- 新增一个
- 删除一个
- 改端口
- 重新生成链接

如果你看到：

```text
vless-in-1
vless-in-2
```

可以理解成：

- 这是不同的 VLESS 入口
- 每个入口都可以有自己的链接

---

### 4）中转管理

这是进阶功能。

如果你完全不懂“上游 SS 中转”是什么意思，**先别碰这里**。

直接用默认直连模式就行。

---

### 5）服务管理

这里最常用。

你可以：

- 启动服务
- 停止服务
- 重启服务
- 查看状态
- 看日志
- 更新 sing-box

如果你改完东西后连不上，优先做这两件事：

1. 重启服务
2. 看日志

---

## 如果你只想要最简单推荐方案

如果你什么都不懂，就按这个来：

- 协议：只开 `VLESS Reality`
- 部署模式：选 `直连落地`
- 地址：留空自动探测，或者填你自己的域名
- 端口：用默认值或一个没冲突的常见端口
- 装好后：复制生成出来的链接到客户端

如果你还想多留一个备用协议：

- 再额外开一个 `SS`

---

## 客户端链接丢了怎么办

没关系。

重新输入：

```bash
sb
```

然后进入：

```text
链接与配置
```

重新查看或重新生成链接就行。

---

## 连不上时先查什么

### 1）先看服务是不是正常启动了

你可以在 `sb` 里进：

```text
服务管理
```

查看状态。

也可以手动执行：

```bash
systemctl status sing-box
```

---

### 2）检查安全组 / 防火墙

这是最常见原因。

请检查：

- 云平台安全组
- 系统防火墙
- 端口是不是被别的程序占用了

---

### 3）检查你复制的是不是最新链接

如果你：

- 改过端口
- 删除重建过协议
- 新增过节点

那旧链接可能已经失效了。

请重新生成后再导入客户端。

---

### 4）如果你用 IPv6

要确认三件事：

- VPS 有公网 IPv6
- 入站 IPv6 已放行
- 你的本地网络也能访问 IPv6

---

## 怎么卸载

### 普通卸载

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/admintors/singbox-deploy/main/uninstall-singbox-yyds.sh)"
```

然后按提示输入：

```text
YES
```

### 直接卸载

```bash
curl -fsSL -o uninstall-singbox-yyds.sh https://raw.githubusercontent.com/admintors/singbox-deploy/main/uninstall-singbox-yyds.sh && chmod +x uninstall-singbox-yyds.sh && ./uninstall-singbox-yyds.sh --yes
```

---

## 给完全新手的最后建议

记住下面几条就够了：

1. 不会就先选 **直连落地**
2. 不会就先只开 **VLESS Reality**
3. 改完端口后，要重新复制链接
4. 连不上先查 **安全组 / 防火墙**
5. 看不懂中转就先不要动
6. 每次改东西前，先留一份旧链接做备份
